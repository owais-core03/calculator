# Calculator Application

A simple and responsive Calculator Application built using HTML, CSS, and JavaScript. This project was developed as part of an internship task to strengthen frontend development skills and JavaScript fundamentals.

## 🚀 Features

* Basic arithmetic operations (+, −, ×, ÷)
* Real-time calculation display
* Responsive and user-friendly interface
* Clean and modern design
* Keyboard-friendly functionality 
* Fast and lightweight performance

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript (ES6)

## 🚀 How to Run

1. Clone the repository:
   git clone https://github.com/owais-core03/calculator.git

2. Open the project folder.

3. Double-click `index.html` or open it in your preferred browser.
